DEAD FREQUENCY

Uma cidade simulada na zona morta, em primeira pessoa e com cara de PlayStation 1. Escolha uma profissão, ganhe um apartamento no Edifício Sintonia, ouça a Rádio 96.6 e ajude a cidade a funcionar — sozinho ou com até 8 amigos online.

01 O jogo

6 profissões

Entregador (caixas que quebram de verdade), taxista, gari, repositor do mercado, frentista e locutor da Rádio 96.6. Cada uma paga do seu jeito.

Rádio 96.6

Músicas originais de bandas fictícias, sincronizadas pelo relógio: todo mundo ouve o mesmo trecho, na van, no mercado ou no apartamento.

Online com os amigos

Salas por código de 5 letras ou pela lista de salas públicas. Servidor oficial grátis, servidor próprio ou hospede no seu PC.

Cidade e sítio

Cidade gerada com ruas, postos, mercado com interior, delegacia, bombeiros, ônibus 966 e pedestres — e um sítio com bichos, celeiros e estradas de terra.

Física tátil

Pegue e arremesse caixas, empilhe na caçamba, dirija a caminhonete, a moto de entrega ou um caminhão emprestado.

Estilo PS1

Low-poly, neblina densa, noites escuras, orelhões das operadoras paródia (tchau, morto e a rara Telefóbica) e outdoors iluminados.

Verificar o download

Cada versão vem com um SHA256SUMS.txt. No Windows, compare com: certutil -hashfile DeadFrequencyLauncher-windows.exe SHA256. Os arquivos também têm atestado de build do GitHub (prova que saíram do GitHub Actions deste repositório, sem mexida no meio do caminho): gh attestation verify ARQUIVO --repo dieguesmosken/dead-frequency. Veja a política de assinatura de código.

O Windows pode avisar que o arquivo é "desconhecido" (o jogo não tem assinatura paga): clique em Mais informações → Executar assim mesmo. Todas as versões: GitHub Releases · código aberto (GPL-3.0) em github.com/dieguesmosken/dead-frequency.

08 Privacidade

  • Jogando sozinho o jogo não envia nada sobre você. Ao abrir, ele só pergunta ao GitHub qual é a última versão (dá para desligar em Opções → Jogo → Procurar atualizações ao abrir).
  • Online (só quando você entra numa sala): o jogo manda ao servidor escolhido o nome que você digitou, a cor, a profissão e o estado da partida (posição, caixas, veículos). O servidor oficial guarda só o resumo das salas abertas (código, nome do anfitrião e número de jogadores, apagado quando a sala fecha) e totais anônimos, como entregas e recorde de jogadores. Nada é vendido nem usado para propaganda. O servidor roda na Cloudflare, que pode registrar o endereço IP das conexões, como qualquer site.
  • Hospedar no meu PC usa o Cloudflare Tunnel (cloudflared) para criar um link público temporário enquanto a partida está aberta.
  • Launcher: consulta e baixa as versões no GitHub. A atualização automática é opcional (ele pergunta na primeira vez).
  • Este site não usa cookies nem rastreamento. Ele carrega fontes do Google Fonts, a última versão pela API do GitHub e as estatísticas públicas do servidor.
  • Desinstalar: apague a pasta onde o jogo foi instalado (a escolhida no launcher). As opções e o save ficam em %APPDATA%\Godot\app_userdata\Dead Frequency (Windows) ou ~/.local/share/godot/app_userdata/Dead Frequency (Linux); apague essa pasta para remover tudo.

Dúvidas: contato@badwolf3d.com.br.

09 Política de assinatura de código

Os arquivos do jogo e do launcher são compilados pelo GitHub Actions direto do código público deste repositório, com SHA256SUMS.txt e atestado de build em cada versão. A assinatura de código para Windows está em processo de solicitação ao programa gratuito para código aberto da SignPath Foundation.

  • Autores e revisores: Matheus (dieguesmosken). Contribuições de outras pessoas (inclusive código gerado com ajuda de IA) só entram depois da revisão dele.
  • Aprovador das assinaturas: Matheus (dieguesmosken). Cada versão assinada é aprovada manualmente.
  • Commits do mantenedor são assinados (selo Verified no GitHub).
